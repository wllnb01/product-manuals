# Product Manuals

Generic, brand-neutral product documentation for marketplace listings.
No brand names, store identifiers or contact details inside — the documents can be reused on any
platform and by any team member.

## Contents

| File | Description |
|---|---|
| `User-Manual-EN.pdf` | Generic user manual, English, A4, 5 pages. Safety, commissioning, operation, care, troubleshooting, disposal, warranty. Applies to household, garden, outdoor, furniture, hand-tool and accessory products. |

## Direct link

```
https://cdn.jsdelivr.net/gh/jingyuxiao318-sketch/product-manuals@main/User-Manual-EN.pdf
```

Paste this URL into the document / instructions manual field of a listing.
jsDelivr serves the file as `application/pdf`, with range requests and a long cache.

## Editing

The layout source is a self-contained HTML file printed to PDF with headless Chrome.
Keep the page height at 296.6 mm with `overflow: hidden`, and check that no block spills past
1060 px (A4 at 96 dpi) before exporting, otherwise content is silently clipped.
